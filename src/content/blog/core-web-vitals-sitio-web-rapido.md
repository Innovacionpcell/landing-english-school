Google mide la experiencia real de tus visitantes con tres métricas llamadas **Core Web Vitals**. Afectan tu posicionamiento, pero sobre todo afectan algo más importante: cuántos visitantes se convierten en clientes.

## Las tres métricas

- **LCP (Largest Contentful Paint)**: cuánto tarda en verse el elemento principal. Meta: menos de 2,5 s.
- **INP (Interaction to Next Paint)**: qué tan rápido responde la página cuando tocas algo. Meta: menos de 200 ms.
- **CLS (Cumulative Layout Shift)**: cuánto "salta" el contenido mientras carga. Meta: menos de 0,1.

## Los culpables más comunes

1. Imágenes pesadas sin formatos modernos (AVIF/WebP) ni tamaños responsivos.
2. Plugins y widgets de terceros que cargan JavaScript innecesario.
3. Fuentes sin precarga que cambian el texto al cargar.
4. Hosting compartido saturado.

## Cómo lo resolvemos

Construimos sitios con arquitectura estática (HTML pre-renderizado), imágenes optimizadas automáticamente y cero JavaScript que no aporte. El resultado: puntajes de 95–100 en PageSpeed y formularios que convierten más.
